# ПЗ 10. Чат реального часу на WebSocket

Практична робота з дисципліни «Прикладне програмування» (КН 3/2).
Чат реального часу: WebSocket-сервер на бібліотеці `ws`, інтегрований з Express,
з розсиланням повідомлень усім клієнтам, подіями приєднання/виходу та лічильником
учасників онлайн.

## Структура

```
server.js            # Express + WebSocketServer (ws), broadcast, події connection/message/close
public/index.html    # клієнт чату (WebSocket API)
test_client.js       # консольний тест двома клієнтами
```

## Запуск

```bash
npm install
node server.js              # http://localhost:3000
# у другому терміналі — консольний тест:
node test_client.js
```

Відкрийте сторінку у двох вкладках, введіть різні імена — повідомлення
з'являються в обох вікнах миттєво.

## Події

| Подія | Опис |
|-------|------|
| `connection` | нове з'єднання, збільшення лічильника онлайн |
| `message` (`join`) | користувач представився іменем |
| `message` (`chat`) | повідомлення, яке розсилається всім (`broadcast`) |
| `close` | вихід учасника, оновлення лічильника |
